Numbers built from bricks, primes as single bricks

The primes are the bricks themselves. The box contains only prime bricks, 2, 3, 5, 7, 11, …, and every other number is something you build from them: each prime brick sets one edge of the finished block. 12 is built from the kit 2, 2, 3. Every number has exactly one kit, and a prime is a kit with a single brick in it.

How the building works

Write the number as a product of primes, smallest first: 12 = 2 · 2 · 3. Start with one brick of length 2. Copy it 2 times side by side: a 2×2 plate. Stack 3 of those plates: a 2×2×3 block of twelve studs. Each prime factor is one copying step, in its own direction.

After three steps every direction is used, so a fourth factor copies the whole block side by side with a small gap, like a module repeated in a building set; a fifth repeats that row of modules, and so on. The number of copying steps is the number of prime factors counted with repetition, the number of directions the number can unfold into.

The primes are the bricks; every other number is a build. Each number comes with exactly one kit of prime bricks, and so exactly one finished block with prime edges: that is the fundamental theorem of arithmetic, in plastic.

Order does not matter for the finished shape: copying 3 times and then 2 times gives the same block as 2 and then 3, just turned. Try the rich numbers like 360 = 2·2·2·3·3·5 or 720, with six or seven copy steps, against a prime like 359 next to them, which stays a single brick.
